Design a File System

<b>  Problem Statement </b>
We need to design a file system like what you see in your OS:
It should allow files and directories (folders).
A directory can contain files and other directories (hierarchy).

Typical operations:
1. Create a file/folder
2. Delete file/folder
3. Move/Rename
4. List contents
5. Get size
6. Search (optional)

7. Permissions/ownership (optional, advanced)
